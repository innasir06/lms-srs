# 📘 Learning Management System (LMS): Software Requirements Specification

An IEEE-style Software Requirements Specification for a university Learning Management System, written as a team project (4 members) for the *Software Engineering Fundamentals* course at Fatima Jinnah Women University (June 2024).

## 📄 Overview
The LMS covers course delivery, student enrollment, assignment submission and grading, and communication between students and instructors.

## ✨ What's Inside
- **Product scope, constraints, and assumptions**
- **35 functional requirements** across user management, course management, assignments, communication, reporting and analytics, content delivery, quizzes and exams, accessibility, and system administration
- **Use case model** with detailed flows: registration, course creation, assignment submission, messaging, and reporting
- **Non-functional requirements:** performance, security, and quality attributes
- **External interfaces:** web UI, SSO, LTI, email notifications, and third-party APIs
- **Data dictionary**

## 🛠 Methods & Tools
IEEE SRS standard • UML • COMET method
